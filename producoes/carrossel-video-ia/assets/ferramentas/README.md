# Logos e gerações das ferramentas

Coloque aqui, por ferramenta, os arquivos que o dono enviar:

- `<ferramenta>-logo.png` (ou `.svg`), de preferência com fundo transparente
- `<ferramenta>-geracao.jpg` (um quadro de uma geração feita na ferramenta, ou imagem oficial de divulgação)

Ferramentas: `freebeat`, `viggle`, `kling`, `seedance`, `capcut`.
Nunca recriar logo de marca por IA nem de memória: só arquivos reais enviados pelo dono.
